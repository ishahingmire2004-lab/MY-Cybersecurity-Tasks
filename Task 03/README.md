# Task-03: Password Complexity Checker

### Objective
Build a tool that checks password strength based on length, uppercase, lowercase, numbers, and special characters.

### Features
- Checks length (minimum 8 chars)
- Checks uppercase & lowercase
- Checks numbers and special characters
- Gives Strength: WEAK / MEDIUM / STRONG + feedback

### How to Run
python password_checker.py

### Example Output
Enter password: Test@1234
Strength: STRONG

### Technologies Used
Python, Regex (re module)
